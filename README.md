# InsightAI — Week 10 Hands-on Activity Prototype

A small working prototype of the proposed **AI-Powered Data Analysis Agent**.

## Core Flow

Upload CSV/Excel → Ask a natural-language question → Groq LLM interprets the question → Python/Pandas performs the calculation → Result is displayed.

The LLM does **not** calculate numerical results. Pandas performs the actual computation.

## Features

- CSV and Excel file upload
- Natural-language data queries
- Groq LLM-based question interpretation
- Pandas-based numerical analysis
- Dataset preview
- Aggregation and grouped analysis
- Average and total calculations
- Interactive Streamlit interface

## Tech Stack

- Python
- Streamlit
- Pandas
- Groq API
- OpenAI-compatible LLM
- python-dotenv
